개념 사전

학습 판단과 안다는 느낌

학습 판단(JOL)과 안다는 느낌(FOK)은 실제 지연 수행의 측정값이 아니라 단서와 친숙함에 바탕을 둔 수행 예측이다.

가까운 개념 유창성에 따른 학습 과대평가

무엇이 학습 판단과 안다는 느낌을 만들까요

학습 판단과 안다는 느낌을 늘리거나, 일어나게 하는 조건이거나, 그 까닭을 설명하는 개념이에요.

  • 유창성에 따른 학습 과대평가는 학습 화면에 답이 함께 보이고 시험 때 단서가 줄어들 때 학습 판단과 안다는 느낌을 늘려요.

    정답이 보이는 학습 화면의 친숙함과 처리 유창성은 도움 없이 인출할 능력을 과대평가하게 만들 수 있다

    연구에서 조건부 확인 · 2005

헷갈리기 쉬운 개념

비슷해 보이지만 구별해서 봐야 하거나, 반대 방향인 개념이에요.

  • 학습 판단과 안다는 느낌은 지연 인출 검사와 구별해서 봐야 해요.

    학습 여부를 확인하려면 노출 직후 친숙함과 도움 없이 지연 뒤 정보를 인출하는 수행을 구분한다
