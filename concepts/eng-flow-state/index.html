flow 상태

flow는 도전과 기술이 균형을 이루고 목표·피드백에 집중해 활동 자체에 완전히 빠져든 경험 상태다.

이 개념과 이어진 것

  • 도전-기술 균형 조건이 된다 → 이 개념
    연구: 조건부 지지 · 2015
  • 동적 난이도 조정 관련 있다 → 이 개념
  • 톱니형 난이도 곡선 관련 있다 → 이 개념
    조건: 톱니형 난이도 조정이 도전≈기술의 몰입 채널을 유지할 때
  • 이 개념 관련 있다 → 경험의 질과 삶의 질
    조건: 몰입이 자발적 목표에서 오는 경우
  • 몰입 진입의 시간 구조 관련 있다 → 이 개념
  • flow의 네겐트로피 관련 있다 → 이 개념
  • 구조가 여가의 flow를 돕는 원리 관련 있다 → 이 개념
  • 게임 페이스 조절 관련 있다 → 이 개념
  • 재미의 반응 정의 관련 있다 → 이 개념
  • Zak의 생리 기반 Immersion 점수 구별된다 → 이 개념
  • 문제 해결형 의도적 몰입 구별된다 → 이 개념
  • 몰입 가능성과 목적의 윤리성 분리 구별된다 → 이 개념
    조건: 몰입 가능성을 도덕적 정당성으로 해석하려 할 때
  • flow의 상승 사다리 늘린다 → 이 개념
  • 능동 여가와 수동 여가 늘린다 → 이 개념
    조건: 여가에 목표와 교감이 없으면 능동 여가의 긍정 효과가 약해진다
  • 지루함과 불안의 비대칭 처방 늘린다 → 이 개념
  • flow를 위한 온보딩 늘린다 → 이 개념
  • 기술을 요하는 도전적 활동 부분이다 → 이 개념
  • 명확한 목표 부분이다 → 이 개념
    조건: 창의 활동의 목표가 모호할 때 내면화된 좋고-나쁨 기준이 있으면 목표·피드백이 보완된다
  • 즉각적 피드백 부분이다 → 이 개념
  • 게임필(game feel) 설명한다 → 이 개념
    조건: 조작 반응의 손맛이 나쁘면 몰입 촉진 효과가 약해진다
  • 기술을 요하는 도전적 활동 조건이 된다 → 이 개념
  • 즉각적 피드백 조건이 된다 → 이 개념
