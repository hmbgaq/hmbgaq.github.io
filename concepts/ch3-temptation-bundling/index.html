가까운 개념 쌍곡 할인 습관 반응

유혹 묶기가 바꾸는 것

유혹 묶기가 늘리거나 줄이거나 설명하는 개념이에요.

  • 유혹 묶기는 습관 반응을 늘려요.

    습관 반응은 신호와 열망 뒤 실제로 수행되는 행동이며 개인의 능력과 환경이 행동 가능성을 뒷받침해야 한다

    연구에서 조건부 확인 · 2014 연구에서 조건부 확인 · 2020

재는 법과 쓰이는 곳

이 개념을 재는 도구, 이 개념이 쓰이는 자리예요.

  • 쌍곡 할인은 유혹 묶기에 쓰여요.

    쌍곡 할인은 시간이 가까워질수록 보상 가치를 비선형적으로 할인해 장기 계획보다 당장의 보상을 과도하게 선호하게 만든다

    연구에서 조건부 확인 · 2020
