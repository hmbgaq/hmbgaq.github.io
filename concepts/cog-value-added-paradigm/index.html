개념 사전

가치 추가 패러다임

교육 기능의 효과는 기본판과 기능 하나만 추가한 판을 비교해 어떤 구성 요소가 결과 차이를 만들었는지 살핀다.

가까운 개념 감각양식 효과의 조건성 중복 효과 대조군의 필요

무엇이 가치 추가 패러다임을 만들까요

가치 추가 패러다임을 늘리거나, 일어나게 하는 조건이거나, 그 까닭을 설명하는 개념이에요.

  • 기본판을 대조 기준으로 두고 기능 하나의 추가 효과를 비교할 때 대조군의 필요는 가치 추가 패러다임이 나타나는 조건이에요.

    개입이 결과를 바꿨는지 판단하려면 개입이 없거나 다른 조건의 비교 집단이 필요할 수 있다

    연구로 확인 · 2019

재는 법과 쓰이는 곳

이 개념을 재는 도구, 이 개념이 쓰이는 자리예요.

  • 복잡성·길이·언어 숙련·청각 환경·접근성이 달라질 때 가치 추가 패러다임으로 감각양식 효과의 조건성을 잴 수 있어요.

    시각 글과 음성을 나누면 특정 조건에서 부담이 줄 수 있지만 음성 우월은 보편 법칙이 아니며 길이·언어·환경·접근성에 달려…

    연구에서 조건부 확인 · 2019
  • 기본판과 한 기능만 추가한 판을 무작위 비교할 때 가치 추가 패러다임으로 중복 효과를 잴 수 있어요.

    중복 효과는 완전한 정보를 여러 형식으로 동시에 강제하면 추가 정보가 도움보다 불필요한 부하가 될 수 있다는 현상이에요

    연구에서 조건부 확인 · 2023
