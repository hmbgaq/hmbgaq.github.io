개념 사전

문제 표상

문제 표상은 현재 상태와 목표 상태, 허용된 조작을 명시해 어떤 변화가 해결인지 정의하는 방식이다.

가까운 개념 후진 탐색

문제 표상이 바꾸는 것

문제 표상이 늘리거나 줄이거나 설명하는 개념이에요.

  • 문제 표상은 후진 탐색이 나타나는 조건이에요.

    후진 탐색은 목표가 명확할 때 필요한 조건을 목표에서 현재 상태 방향으로 거슬러 찾아간다

    연구에서 조건부 확인 · 2026
  • 문제 표상은 같은 문제의 서술이나 관점을 바꾸었을 때 표상 관점과 문제 난이도를 설명해 줘요.

    같은 구조의 문제도 서술과 관점이 달라지면 난이도가 달라질 수 있어 해결 정체를 능력 부족으로 보기 전에 표상을 점검한다

  • 문제 표상은 수단-목적 분석이 나타나는 조건이에요.

    수단-목적 분석은 현재 상태와 목표의 차이를 찾고 그 차이를 줄이는 조작을 반복하는 탐색 전략이다

문제 표상을 이루는 것

이 개념의 한 부분이거나 한 종류인 개념이에요.

  • 제약 장부는 문제 표상의 일부예요.

    제약 장부는 원문이나 환경에서 실제로 주어진 제약과 해결자가 스스로 추가한 암묵 제약을 구별해 적는다

재는 법과 쓰이는 곳

이 개념을 재는 도구, 이 개념이 쓰이는 자리예요.

  • 문제 표상은 IA를 설계하기 전에 실제 사용자의 문제를 정의할 때 노먼의 이중 다이아몬드에 쓰여요.

    이중 다이아몬드는 먼저 문제를 발견·정의하고 다음으로 해결책을 발전·전달하는 두 발산·수렴 국면을 거친다
